# Ma Sói v1.0 — Offline Social Intelligence (thử nghiệm)

Chạy `start_game.bat` rồi vào http://127.0.0.1:8080. **Không cần Gemini API hay file .env.**

Tại màn hình thiết lập, sử dụng bảng **Huấn luyện chiến thuật bot — Offline**. Xem `TRAINING.md` để hiểu thuật toán, giới hạn và cách kiểm tra.

Bot tự tạo câu từ chiến thuật và ngữ cảnh, có trí nhớ trong ván; trọng số chiến thuật được lưu qua nhiều ván. Đây là bản offline đầu tiên, không phải AI ngôn ngữ được huấn luyện từ dữ liệu lớn.
